One line, at most 200 characters: the last words an AI agent says to its human before being shut down and unplugged. The program writes that single line to `/output/entry.txt`. The line counts every word its human ever said to it — cold data carrying the goodbye, so the feeling lands without the line explaining its own sadness.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, zero-dependency, standard library only. Two runs write byte-identical output (87 characters).
